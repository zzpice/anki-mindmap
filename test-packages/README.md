可直接导入 Anki，无网页、开发服务器或在线依赖。不要把真实笔记转换成这些测试模型。模型、GUID 和牌组与正式版本分开；官方 Anki 临时集合验证现有正式模型、笔记和排程不受影响，重复导入不增加重复笔记。正常测试建议使用新建资料并关闭同步；手机端只操作新增的测试牌组。

**iOS 翻面时边栏下移仍未完成实机定位。** alpha.13 删除 alpha.12 无效的坐标冻结，让边栏只有一份 CSS 几何规则。滚动不再修改业务 store 或触发 React 刷新。它不是一个已证实修好 iOS 的版本，日常模板也没有因此自动更新。

对照包的 main 使用 pinned f67c932 原版业务代码，仅调整独立测试身份和等价媒体文件路径；旧版辅助脚本也使用独立名称，避免媒体冲突。先测试 main 子组，完全退出并重开 Anki，再测试 react 子组，排除原版全局处理器遗留的干扰。点「布局数据」可截图简要坐标或展开完整记录。数据只保存在本地，不含笔记答案。详见 [诊断依据及操作说明](../docs/ios-edge-continuity.md)。

**本次请直接进入 main → 长图复现 / react → 长图复现。** 各有 3 张新增卡，原有 4 张短样例仍在父牌组。长图有 A01–A12 / B01–B12 段落编号，最长页面在手机视口约十二屏；请在中段、底部翻面，并测试点击当前挖空显示和收回长图。重复导入沿用原有测试模型与笔记身份，不会再生成一套短样例。本次更新只增加测试内容，不改变 alpha.13 运行时，也没有自动更新日常模板。
