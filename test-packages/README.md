可直接导入 Anki，无网页、开发服务器或在线依赖。不要把真实笔记转换成这些测试模型。模型、GUID 和牌组与正式版本分开；官方 Anki 临时集合验证现有正式模型、笔记和排程不受影响，重复导入不增加重复笔记。正常测试建议使用新建资料并关闭同步；手机端只操作新增的测试牌组。

**alpha.14 针对实际测量修复边栏参照。** 用户 alpha.13 在同一正面展开其他分支时，根高度保持 606，而窗口/可见高度变为 681/684，边栏随之后移。现在读取当前根布局高度，由 CSS 统一分半，不缓存正面坐标。用户已反馈 alpha.14 在这张原卡的展开分支步骤中稳定；这不代表所有 iOS/Android 场景都已验证。圆点裁切另以最外层树增加 10px 留白修复。日常模板没有因此自动更新或同步。

对照包的 main 使用 pinned f67c932 原版业务代码，仅调整独立测试身份和等价媒体文件路径；旧版辅助脚本也使用独立名称，避免媒体冲突。先测试 main 子组，完全退出并重开 Anki，再测试 react 子组，排除原版全局处理器遗留的干扰。点「布局数据」可截图最初正面与当前坐标或展开完整记录。数据只保存在本地，不含笔记答案。详见 [本次依据](../docs/ios-layout-viewport.md)与[历史诊断步骤](../docs/ios-edge-continuity.md)。

各版「长图复现」子组保留 3 张长图卡，原有 4 张短样例仍在父牌组。长图有 A01–A12 / B01–B12 段落编号，最长页面约十二屏；可在中段、底部翻面并测试长图答案。也请在正面展开其他折叠分支，检查边栏与圆点。重复导入沿用原测试模型与笔记身份，不另生成一套牌组。实际原卡对照包含个人内容，只在本地提供，不上传本仓库。

正常 React 版保留折叠、定位、当前挖空逐处显隐、其他组显隐、搜索、导图、批注、互链、主题和输入适配。Anki 仍负责正式翻面与评分。已删除填写笔记弹窗，原字段与内容保留；正文图片交给客户端原生手势。

验证结果与限制见 [verification.json](verification.json)，包身份和摘要见两份 manifest 与 [SHA256SUMS](SHA256SUMS)。[原版视觉对照](visual-comparison/README.md)包含历史基线；当前浏览器/隔离 Desktop 结果不能代替 AnkiMobile、AnkiDroid 实机认证。没有合并 main 或发布正式 Release。
