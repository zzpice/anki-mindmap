# Alpha.5：边栏短标签与 Android 触控

仅处理边栏可辨认性与触控响应。保留顶部牌组路径、正文知识标题、原边栏位置和宽度、正文边距、主题底色与动效。

标签为「定位」「导图」「展开／收起」「答案」。答案仍只控制其他编号的自定义挖空；当前答案与 Anki 正式翻面规则不变。文字放在原边栏可见的一半内，使用正文现有文字颜色，不扩大透明点击区域覆盖正文。

Android 的边栏此前只走 React click；现在轻触松手时立即调用原按钮 click，仍由原 React handler 发出统一业务命令，不另写一套操作。与正文共用 tap.ts 的手势识别：滑动、多指、取消均不触发；后续兼容 click 被去重；键盘和鼠标仍走原入口。iOS 侧栏仍走原按钮路径，正文既有轻触规则保持。

触摸或滚动打断定位时，旧投影会重复设置整棵树的属性。content.ts 现在按不可变 store 快照的引用判断哪些部分需要投影；它只记住上一次呈现结果，业务状态仍只有 core.ts 一份。未变化的树、答案和其他挖空不再重复写 DOM，主题和缩放也只在变化时设置。

验证包括：每个浏览器引擎四个边栏按钮在 touchend 返回前恰好执行一次，兼容 click 零重复，拖动零操作；连续 50 次打断指令产生零正文 DOM 变更。保留两引擎各 100 次生命周期、十次 Android 式导航和原有触控回归。320／390 px、明暗两模式共八个视图的标签与正文边距检查通过。Anki Desktop 使用隔离资料；Android 本轮响应感受仍需实机复测。
