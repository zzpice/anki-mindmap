# 变更记录

## 2026-10-24：React 并入 main 与仓库整理

- 将已验证的 React 开发历史合并到 main，版本仍为 0.2.0-alpha.14；未额外创建稳定版标签或 Release。
- 首页改为中文下载／使用入口，文档增加导航；阶段性记录归入 history/。
- 清理无人调用的旧预览壳、兼容脚本别名、重复旧测试、旧媒体与过期截图／完整测量。固定提交和迁移指纹保留历史，不重写 Git 历史。
- 修正 NOTICE 的 React / React DOM / Scheduler 说明，诊断包补齐 mark.js 全文许可证。运行时及 Anki 数据契约未改。
- 当前测试包下载文件名保持不变，GitHub Actions 继续构包和回归，不增加部署。
- main 的 CI 通过后清理已完整并入的 React 开发分支，默认维护入口统一到 main；固定提交仍可查回全部历史。

## 0.2.0-alpha.14

根据实际 iOS 复现读取当前根布局高度，不再跟随内容引起的可见高度扩张；边栏几何统一由 CSS 决定，不恢复坐标缓存。用户报告同卡展开其他分支时已稳定；其余手机路径继续复测。最外层树额外留出 10px，使折叠圆点外圈完整。详见[布局依据](ios-layout-viewport.md)。

## 主要演进

| 阶段 | 保留在当前版本的变化 |
| --- | --- |
| alpha.1–2 | React 状态核心、独立正文模块、离线打包；恢复原文楷、主题和树形视觉 |
| alpha.3–5 | 翻面加载保护、移动触控去重、Android 轻触松手即时响应 |

| alpha.12–13 | 撤回无效坐标冻结，清理重复边栏规则与滚动触发的无效业务更新 |

所有阶段的业务规则、字段及原生 Cloze 以当前实现和验收为准；已撤回的尝试只作为[历史记录](history/README.md)，不是未来实现模板。
