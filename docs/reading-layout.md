# 阅读位置与正反面衔接

正文知识标题保留，字号从 26 px 调为 20 px，行高 28 px；缩短标题下方留白，取消 40 px 的最低高度。顶部牌组路径照常保留。长标题允许换行，不截断或删除字段。

边栏宽度与正文边距不变。左上「导图」、左下「定位」，右上「展开／收起」、右下「答案」。答案按钮仍只控制其他编号的自定义挖空。原有底色、字体、连接线、主题和动画不在本轮调整。

直接点开／隐藏挖空时，尽量保持答案起点在屏幕上的位置，内容向下自然展开；不会为长答案预留大块空白。逐步揭示只在目标已经离开可读区域时滚动，避免每次都把正文重新居中。显隐仍通过同一业务命令完成。

同一张卡正面翻到背面时，保留其他分支的手动展开状态、缩放和阅读位置，当前答案的必要祖先重新展开；背面仍允许随后手动折叠。当前答案由 Anki 原生背面显示，其他答案、搜索和弹窗状态重置。下一张正面重新开始。定位按钮仍会展开考查路径并定位答案。

## 实现边界

- `core.ts` 仍是唯一业务状态来源，`restoreLayout` 只接受已知节点的展开值和有效缩放，不接收答案或弹窗状态。
- `continuity.ts` 在 sessionStorage 中保存一份仅用于正面到背面的布局快照。每个新正面都会覆盖它，即使正文完全相同；背面只消费一次。旧页面的卸载回调不能覆盖新页面的快照。正文、字段值和答案不会写入存储。
- 标准 Anki 模板没有通用卡片 ID 字段，因此以惰性模板中的正文摘要、牌组、原生 Cloze ordinal 和节点结构共同匹配。该惰性模板不展示、不执行正文，也不生成卡片。超过 30 分钟、编号或结构不符、缺少元数据、存储不可用时，安全退回首次定位。双 WebView 不共享 sessionStorage 时也可能无法延续位置。直接打开背面通常不延续；在没有经过新正面的情况下，立即直接打开内容及编号完全相同的另一张背面，标准模板无法严格区分，可能沿用布局。答案状态始终不继承。
- `reading.ts` 只记录元素路径和屏幕位置。在显隐或翻面后，短暂观察正文尺寸变化，补偿图片／公式的延迟排版；最多持续两秒。任何手动触控、鼠标、滚轮、键盘命令都会取消。观察器、计时器与卡片一起释放，不进行持续自动定位。
- 受浏览器滚动边界、极长内容和客户端宿主时序限制，不能保证任意内容绝对不移动。目标是稳住正在看的起点，允许下面的正文自然增高。

## 验证

自动检查包含：直接揭示起点稳定、Android 式整页翻面保留展开和阅读位置、相同正文的新正面重置、不同原生 ordinal 隔离、延迟排版补偿、手动取消、存储过期／不可用降级、卸载资源清零。保留两引擎各 100 次生命周期及原有离线、原生 Cloze、触控和搜索回归。

视觉回归仍比较固定旧版的字号、颜色、连接线和控件宽度。标题压缩、边栏分区与 alpha.14 最外层树增加 10px 留白是明确批准的差异；窄屏长句可能提早换行，因此不再要求正文纵坐标等同旧版。浏览器及隔离 Desktop 证据不代表手机实机认证，当前结论见[验证结果](validation.md)。
