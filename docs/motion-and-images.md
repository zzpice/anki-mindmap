# Alpha.9–11：轻量反馈、原生图片手势与边栏定位

本轮在 feat/react-rewrite 的 6da8e89 上开发，保留原有纸色、字体、节点和阅读定位规则。

## 实际变化

- 正文图片不再触发模板的大图弹窗，也不取消图片的 touchend / click / dblclick。图片位于已揭示的 Cloze 内时，同样交给客户端处理，不顺带隐藏答案。独立导图入口、导图字段和批注弹窗保留；弹窗图片不再套第二层查看器。模板不再提供自己的图片放大回退，具体缩放方式由客户端决定。
- 按钮和节点圆点按下时立即降低不透明度，释放后约 90ms 恢复；动作本身不延后。
- 搜索、导图、批注面板仅做 140ms 淡入；关闭立即卸载，不为退出效果留下计时器或遮挡层。
- 手动定位、执行搜索、切换命中后，对目标做一次 560ms 的边框淡出提示。自动开卡定位不提示；答案、正文和边栏不淡入，不移动、不伸缩。
- 跟随系统“减少动态效果”。设置改变时也会取消正在播放的定位提示；不清除公式的静态 transform。

## 边栏回退：以手机反馈为准

Alpha.9/10 曾尝试把四块边栏放入共享定位框，并改为明确的竖排文字。两种浏览器及隔离 Desktop 的尺寸／文字盒中心检查均通过，但用户随后提供手机截图：iOS 右侧文字被裁切，左侧文字偏向内沿，并反馈两端分区和居中有异常。Android 截图相对较轻，不能据此认定 iOS 也正常。

**Alpha.11 撤回新增共同定位框，恢复四块独立 fixed 边栏，并直接处理截图里的裁切风险。** 按钮整体放在屏幕内，宽度为旧按钮露出的半宽（1em），不增加正文占用。左右贴边、上下对半，文字以明确换行的横排字形居中，禁用边栏文字自动放大；不使用竖排字形、离屏半按钮、视口单位或手算缩放。保留原有颜色与阴影，圆角只在朝正文一侧。

动效、取消重复图片查看器、减少动态效果和资源清理保留。这是基于实机截图的定点修正，不再重做整个边栏层级。

这次撤回了共同定位框并修正裁切风险，**不表示原先 iOS 翻面／滑动时的轻微跳动已经修复**。实机字形／WKWebView 排版可以偏离浏览器测量的文本盒，不能再用模拟中心检查作为手机认证。两张用户截图只留在本机，不上传仓库或测试包。后续须以修正后的实机画面继续定位。

## 所有权和清理

core.ts 仍是唯一业务状态；只移除了不再使用的 image 弹窗状态。motion.ts 管理一次性的视觉提示，不保存答案、树或搜索状态。resources.ts 追踪 Web Animations；完成、替换和卸载同步取消并解除回调。CSS 面板动画随 React 元素卸载而消失。没有增加动效依赖，也没有整树 transform 或翻面动画。

## 本轮验证

- 类型、静态离线与身份检查，生产构建：通过。
- 官方 Anki 25.9.2 / 26.9.3 临时集合构包、Cloze ordinal、字段/媒体往返和现有模型/排程不受测试包影响：通过。测试包为独立模型 1792748414，21 条笔记、27 张卡。
- 9 项业务测试、Chromium / WebKit 各 54 个原生正反面样例，以及每个引擎各 100 轮挂载／翻面／切卡：通过。压力测试包含定位提示尚未结束时换卡，卸载后全部资源计数为 0。
- 新增手机模式检查（检查明确换行标签的中心和整个按钮是否位于屏幕内）：长卡滚动、宽答案揭示、翻面、1.1 倍复习缩放、横竖屏变化，四块边栏几何稳定，标签文本盒在可见区域的上下/左右中心偏差小于 0.6 CSS px（不等同于手机字形正常）；图片触控/兼容点击未被取消；导图不产生嵌套弹窗；减少动态效果包括中途开启：通过。
- Alpha.10 曾通过原版对照 108 对、60 个交互场景，但已被实机回归反馈推翻其边栏可靠性结论。Alpha.11 重新通过 108 对与 60 个交互场景，但不把它冒充当前手机认证。
- Anki Desktop 26.9.3，Qt 6.11.0 隔离资料，54 个预览面、5 个真实 reviewer 步骤：通过；每个预览面额外检查边栏半高与文字中心。具体环境以 test-packages/verification.json 为准。
- iOS / Android 原生图片放大手势、iOS 滚动回弹和 Android 轻微翻面短闪：本轮无手机实机，仍需复测。没有用动效掩盖 Android 短闪。

复现：按 README 构建和构包后执行 npm test；新增回归在 tests/react/motion.cjs，沿用既有 reading / viewport / touch / navigation 测试。build/ 中保存本地详细结果；公开 verification.json 不包含个人卡片内容。
