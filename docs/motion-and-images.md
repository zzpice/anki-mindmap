# Alpha.9：轻量反馈、原生图片手势与边栏定位

本轮在 feat/react-rewrite 的 6da8e89 上开发，保留原有纸色、字体、节点和阅读定位规则。

## 实际变化

- 正文图片不再触发模板的大图弹窗，也不取消图片的 touchend / click / dblclick。图片位于已揭示的 Cloze 内时，同样交给客户端处理，不顺带隐藏答案。独立导图入口、导图字段和批注弹窗保留；弹窗图片不再套第二层查看器。模板不再提供自己的图片放大回退，具体缩放方式由客户端决定。
- 按钮和节点圆点按下时立即降低不透明度，释放后约 90ms 恢复；动作本身不延后。
- 搜索、导图、批注面板仅做 140ms 淡入；关闭立即卸载，不为退出效果留下计时器或遮挡层。
- 手动定位、执行搜索、切换命中后，对目标做一次 560ms 的边框淡出提示。自动开卡定位不提示；答案、正文和边栏不淡入，不移动、不伸缩。
- 跟随系统“减少动态效果”。设置改变时也会取消正在播放的定位提示；不清除公式的静态 transform。

## iOS 边栏位置／长度跳动

用户确认部分卡片翻面和上下滑动时仍会跳动。本轮把四块分别 fixed 的边栏改为同一个 fixed 定位框里的 absolute 子控件，使它们共享定位参照。定位框不做 transform 或动效，也不拦截正文手势。用 100svh 保持稳定的小视口高度，旧客户端回退 100vh。CSS zoom 会一并缩放视口长度，因此仅对框高作反向补偿；边栏宽度、文字仍保持原有复习缩放行为。

[MDN 的视口单位说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length#relative_length_units_based_on_viewport)区分稳定的小视口和随浏览器界面变化的动态视口。这里选择前者，不在每次 scroll 中重新测量和写入边栏尺寸。正文宽表格仍在自己的容器内横向滚动。

这是针对当前固定布局的修正，**不表示已经复现或消除了 iOS 实机的全部跳动**。浏览器不能模拟 AnkiMobile 原生工具栏、橡皮筋回弹和 WKWebView 合成器。更新后重点复测原先会跳的卡：正反面、连续上下滑动、底部回弹、横竖屏、原生图片缩放；不要用普通 Safari 通过替代 AnkiMobile 认证。

## 所有权和清理

core.ts 仍是唯一业务状态；只移除了不再使用的 image 弹窗状态。motion.ts 管理一次性的视觉提示，不保存答案、树或搜索状态。resources.ts 追踪 Web Animations；完成、替换和卸载同步取消并解除回调。CSS 面板动画随 React 元素卸载而消失。没有增加动效依赖，也没有整树 transform 或翻面动画。

- 类型、静态离线与身份检查，生产构建：通过。
- 官方 Anki 25.9.2 / 26.9.3 临时集合构包、Cloze ordinal、字段/媒体往返和现有模型/排程不受测试包影响：通过。测试包为独立模型 1792748414，21 条笔记、27 张卡。
- 9 项业务测试、Chromium / WebKit 各 54 个原生正反面样例，以及每个引擎各 100 轮挂载／翻面／切卡：通过。压力测试包含定位提示尚未结束时换卡，卸载后全部资源计数为 0。
- 新增手机模式检查：长卡滚动、宽答案揭示、翻面、1.1 倍复习缩放、横竖屏变化，四块边栏几何稳定；图片触控/兼容点击未被取消；导图不产生嵌套弹窗；减少动态效果包括中途开启：通过。
- 与原版对照：两种引擎、三种宽度、纸色／竹露／夜间、相同原生正反面，共 108 对和 60 个交互场景通过。边栏半屏高度检查允许小于 0.5 CSS px 的计算舍入，其余原有视觉断言保留。
- Anki Desktop 26.9.3，Qt 6.11.0 隔离资料，54 个预览面、5 个真实 reviewer 步骤：通过。具体环境以 test-packages/verification.json 为准。
- iOS / Android 原生图片放大手势、iOS 滚动回弹和 Android 轻微翻面短闪：本轮无手机实机，仍需复测。没有用动效掩盖 Android 短闪。
